## User Story: Tournament Organizer

**As a** tournament organizer,  
**I want** to enter and maintain handicap sets,  
**So that** I can ensure fair competition among participants.

**Acceptance Criteria:**
1. The system allows me to add new handicap sets.
2. I can update existing handicap sets.
3. I can delete handicap sets that are no longer needed.
4. The system provides a way to view all current handicap sets.

**As a** tournament organizer,  
**I want** to add and maintain archers,  
**So that** I can manage participant information efficiently.

**Acceptance Criteria:**
1. The system allows me to add new archers.
2. I can update existing archer information.
3. I can delete archers who are no longer participating.
4. The system provides a way to view all registered archers.

**As a** tournament organizer,  
**I want** to view and manage bow classes,  
**So that** I can configure the available bow classifications for tournaments.

**Acceptance Criteria:**
1. The system allows me to view all available bow classes.
2. I can add new bow classes with ID, name, and description.
3. I can update existing bow class information.
4. I can delete bow classes that are no longer needed.
5. The system shows which archers are using each bow class.
6. I can search and filter bow classes by bow type, age group, or gender.
