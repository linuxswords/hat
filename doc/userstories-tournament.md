## User Story: Conduct a Tournament

**As a** tournament organizer,  
**I want** to conduct a tournament,  
**So that** I can manage the event from start to finish.

**Acceptance Criteria:**
1. The system allows me to create a new tournament.
2. I can update tournament details as needed.
3. I can delete tournaments that are canceled.
4. The system provides a way to view all scheduled tournaments.

## User Story: Enter Tournament Data

**As a** tournament organizer,  
**I want** to enter tournament data,  
**So that** I can keep track of all relevant information.

**Acceptance Criteria:**
1. The system allows me to input tournament name, date, and location.
2. I can update tournament data if changes occur.
3. The system provides a way to view all entered tournament data.

## User Story: Choose Handicap Set for Tournament

**As a** tournament organizer,  
**I want** to choose a handicap set for the tournament,  
**So that** I can apply the appropriate rules for scoring.

**Acceptance Criteria:**
1. The system allows me to select a handicap set from existing ones.
2. I can change the selected handicap set if needed.
3. The system provides a way to confirm the selected handicap set for the tournament.

## User Story: Assign Archers to Tournament

**As a** tournament organizer,  
**I want** to assign archers to the tournament,  
**So that** I can efficiently manage participant entries.

**Acceptance Criteria:**
1. The system allows me to add archers to a tournament.
2. I can remove archers from a tournament if necessary.
3. The system provides a way to view all archers assigned to a tournament.

## User Story: Add Raw Scores for Archers

**As a** tournament organizer,  
**I want** to add the raw scores for archers efficiently,  
**So that** I can quickly process tournament results and generate rankings.

**Acceptance Criteria:**
1. The system allows me to input raw scores for each archer in a tournament.
2. I can update scores if corrections are needed.
3. The system automatically calculates adjusted scores (raw score * handicap factor) for each archer.
4. The system displays a ranking list of tournament scores, ranked by adjusted score from highest to lowest.
5. The ranking list shows archer names, bowclass, raw scores, handicap factors, and calculated adjusted scores.

## User Story: Generate Ranking List as PDF

**As a** tournament organizer,  
**I want** to generate a ranking list as a PDF,  
**So that** I can easily distribute the results to participants and stakeholders.

**Acceptance Criteria:**
1. The system allows me to generate a PDF of the ranking list.
2. The PDF includes all relevant details such as archer names, bowclass, handicap factor, scores, and rankings.
3. I can download and share the PDF with others.

## User Story: Send Messages to Archers via Email

**As a** tournament organizer,  
**I want** to send messages to all archers participating in a tournament via email,  
**So that** I can efficiently communicate important information and updates.

**Acceptance Criteria:**
1. The system allows me to compose a message to all participating archers.
2. I can send the message to all archers' registered email addresses.
3. The system provides a confirmation of successful message delivery.
