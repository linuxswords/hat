# Glossary

## Archer

Is an athlete whop participates in an archery competition/tournament. An archer usually shoots a bow that belongs to a particular bow class. It is possible for an archer to shoot multiple bow classes.
But he is not allowed to change bow classes during a competition/tournament. An archer has a name, gender, bow class and an email address. The email address is used to contact the archer in case of changes to the tournament or competition.

## Bow Class

A bow class or bow category is a classification of a bow and the archer who uses it. It usually entails the age and gender of the archer and the type of bow used.
Adult Male Longbow (AMLB) is an example of a bow class. It is possible for an archer to shoot multiple bow classes, but he is not allowed to change bow classes during a competition/tournament.

The characteristics of a bow differ from each other. There are bows like compound bows that have a lot of technology in them, and there are bows like longbows that are very simple. The bow class determines the rules that apply to the bow and the archer. This results in higher/lower average scores depending on the bow class. The age and gender also factor into the average score of bow class.

## Tournament

A tournament is a competetion in which multiple archers compete against each other. A tournament has a location, a name, a start date, an end date. If the tournament is using a handicap system a handicap set is used to compare the scores of archers that shoot different bow classes.

The winner of a tournament is the archer with the highest score. The score is calculated by the score the archer shot during the tournament, adjusted by the handicap of the bow class he shot.

## Handicap

Aka handicap entry.

To be able to compare the scores of archers that shoot different bow classes, a handicap is used. The handicap is a factor that is applied to the score of an archer to make it comparable to the scores of other archers. The handicap is calculated by comparing the average scores of the bow classes in high-level competitions and normalizing the scores to a common scale.

For example, if the average score of the top 5 archers in the Adult Male Freestyle Unlimited (AMFU) bow class is 600 and the average score of the top 5 archers in the Adult Male Historical Bow (AMHB) bow class is 500, the handicap for the AMFU bow class might be 0.833 and the handicap for the AMHB bow class might be 1.0. This means that if an archer in the AMFU bow class scores 600, it is equivalent to a score of 500 in the AMHB bow class when applying the handicap.

```
Average Score AMFU * handicap AMFU = Average Score AMHB * handicap AMHB
600 * 0.833_ = 500 * 1.0
```

In general we use the AMHB bow class as the base class for the handicap calculation. This means that the handicap for the AMHB bow class is always 1.0 and the handicaps for all other bow classes are calculated relative to it.

## Handicap Set

Is a set of handicaps that are used to compare the scores of archers that shoot different bow classes. A complete set of handicap is a set that contains all the possible bow classes.

## Scores

To clear up the terminology for scores we distinguish between the following types of scores:
- **Raw Score**: The score that an archer shoots during a tournament. This is the actual score that is recorded.
- **Adjusted Score**: The score that is adjusted by the handicap of the bow class the archer shot. This is the score that is used to compare the scores of archers that shoot different bow classes. It is calculated by multiplying the raw score with the handicap of the bow class.
